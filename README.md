## Data and Script Preparation

The folder **Soil_Scripts** contains the analysis scripts for **microbial single-cell RNA sequencing (mscRNA-seq) data from crop rhizosphere soils**.

The corresponding **processed expression matrices** and **species annotation files** are available at:

https://doi.org/10.6084/m9.figshare.31872934

Please download the dataset to obtain the folder **Soil_Matrix**.

For subsequent analyses, place the **Soil_Matrix** folder and the **Soil_Scripts** folder in the **same directory**, as shown below:

```text
project_directory/
├── Soil_Scripts/
│   ├── Figure3/
│   ├── Figure4/
│   ├── Figure5/
│   └── Figure6/
└── Soil_Matrix/
```

Once the folders are organized in this structure, the analysis scripts can be executed directly.

## Origin and Generation of the Soil_Matrix Dataset

The **Soil_Matrix** folder contains two main types of processed data used for downstream analyses:

1. **Single-cell taxonomic annotation results**
2. **Single-cell gene expression matrices**

These data were generated from raw paired-end mscRNA-seq reads from crop rhizosphere soil samples using the workflow described below.

### 1. Taxonomic Identification of Microbial Cells

Raw paired-end reads were first processed using the laboratory preprocessing pipeline for barcode/UMI-aware read processing. The processed reads were then taxonomically classified against a customized microbial reference database using the **scMeta** pipeline. The resulting taxonomic assignments were used to identify microbial species detected in each sample.

The main preprocessing and taxonomic classification steps were:

```bash
# Read preprocessing and barcode/UMI processing
anchorbcm.o \
  -1 <(zcat sample_r1.fq.gz) \
  -2 <(zcat sample_r2.fq.gz) \
  -b prev6v2.msr \
  -o clean_data/sample_

# Taxonomic classification
python scMeta.py --cfg config.ini

# Extract detected species
tail -n +2 Result/sample_sc_taxonomy.report | \
awk -F '\t' '$7 >= 0 && $8 >= 0 {print $3}' | \
sort -n | uniq > species.txt
```

The identified species were subsequently used to select the corresponding microbial reference genomes:

```bash
python selectGenomes.py \
  -i species.txt \
  -r refseq_mapping.tsv \
  -d raw \
  -o ref/genome
```

The species annotation files in **Soil_Matrix** therefore originate from taxonomic classification of the processed single-cell sequencing reads and are independent of the downstream gene expression matrix.

### 2. Construction of the Microbial Reference Genome

Reference genomes corresponding to the identified microbial species were combined into a unified microbial reference genome. A STAR genome index was then generated for downstream single-cell alignment:

```bash
STAR --runThreadN 10 \
  --runMode genomeGenerate \
  --genomeDir ref/STAR_index \
  --genomeFastaFiles ref/genome.fna \
  --sjdbGTFfile ref/genome.gtf \
  --sjdbOverhang 122
```

### 3. Generation of the Single-Cell Gene Expression Matrix

Processed reads were subsequently aligned to the unified microbial reference genome using **STARsolo**. Cell barcodes and UMIs were extracted from the sequencing reads, and gene-level expression was quantified using the `GeneFull` feature:

```bash
STAR --runThreadN 10 \
  --soloType CB_UMI_Simple \
  --soloCBwhitelist 20bp.whitelist.txt \
  --genomeDir ref/STAR_index \
  --soloCBstart 1 \
  --soloCBlen 20 \
  --soloUMIstart 21 \
  --soloUMIlen 8 \
  --readFilesIn clean_data/sample_2.fq clean_data/sample_1.fq \
  --outSAMtype BAM SortedByCoordinate \
  --soloFeatures GeneFull \
  --soloStrand Reverse \
  --soloCellFilter TopCells 10000
```

The resulting STARsolo output was further processed for cell-level quality control and downstream analyses. The final **expression matrices in `Soil_Matrix` represent UMI-resolved single-cell gene expression profiles generated by mapping processed reads to the unified reference genomes of the taxonomically identified microbial species**.

### 4. Overall Data Generation Workflow

The relationship between taxonomic annotation and gene expression quantification is summarized below:

```text
Raw mscRNA-seq reads
        │
        ├── Read preprocessing
        │   └── Barcode/UMI processing
        │
        ├── Taxonomic classification
        │   └── Species annotation
        │
        └── Identified microbial species
                │
                ├── Reference genome extraction
                │
                ├── Unified microbial reference genome
                │
                └── STARsolo alignment and quantification
                        │
                        └── Single-cell gene expression matrix
```

The resulting **species annotation files** and **gene expression matrices** are provided in the **Soil_Matrix** folder and serve as the input data for the downstream analyses in **Soil_Scripts**.

| Software / Package | Version | Main application |
|---|---|---|
| **Trimmomatic** | **v0.39** | Adapter trimming and quality filtering of raw sequencing reads |
| **Kraken2** | **v2.1.3** | Taxonomic classification and construction of the customized gOTUs reference database |
| **Bracken** | **v2.8** | k-mer distribution and taxonomic abundance estimation |
| **STAR** | **v2.7.10b** | Reference genome indexing and read alignment |
| **Seurat** | **v5.3.0** | Single-cell expression matrix processing, clustering, visualization, and downstream analysis |
| **Harmony** | **v1.2.3** | Batch-effect correction and data integration |
| **hdWGCNA** | **v0.4.6** | Single-cell co-expression network, module, and hub-gene analysis |
| **WGCNA** | **v1.74** | Weighted gene co-expression network analysis |
| **Monocle3** | **v1.4.26** | Pseudotime and trajectory analysis |
| **edgeR** | **v4.0.16** | Differential expression and replicate-level pseudobulk analysis |
| **glmGamPoi** | **v1.14.3** | Gamma-Poisson generalized linear modeling for expression analysis |
| **Matrix** | **v1.6.5** | Sparse matrix representation and computation |
| **irlba** | **v2.3.5.1** | Fast truncated singular value decomposition |
| **dplyr** | **v1.1.4** | Data manipulation and transformation |
| **tidyr** | **v1.3.1** | Data tidying and reshaping |
| **tidyverse** | **v2.0.0** | Data manipulation and visualization framework |
| **ggplot2** | **v4.0.0** | Data visualization and figure generation |
| **ggrepel** | **v0.9.6** | Non-overlapping text labels in plots |
| **patchwork** | **v1.3.2** | Combination and layout of multiple ggplot figures |
| **cowplot** | **v1.2.0** | Figure composition and plot arrangement |
| **ggsci** | **v3.2.0** | Scientific journal-style color palettes |
| **RColorBrewer** | **v1.1.3** | Color palettes for data visualization |
| **viridis** | **v0.6.5** | Perceptually uniform color palettes |
| **SeuratWrappers** | **v0.4.0** | Integration of Seurat with external single-cell analysis tools |
